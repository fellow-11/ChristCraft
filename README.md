# Christian Minecraft!
![Discord](https://img.shields.io/discord/1406336513603665981?logo=discord&logoColor=white&label=Discord&color=5865F2&link=https%3A%2F%2Fdiscord.gg%2FSQQKpfJXKy)

The Bible instructs us to "abhor what is wicked" - Romans 12:9, _New World Translation_.

The idea of this pack is to remove spiritism or violence where possible, while not changing too much about the game and specifically trying to keep Minecraft fun and balanced.

### WARNING: Newer versions of ChristCraft only support being added as a fabric mod.
This was necessary to modify minecraft features/structures that are not yet data-driven. Thank you for your understanding.


**Please, join the discord server! You can suggest changes or additions, and report issues on the GitHub project. We need ideas!** Also, if you have experience with hardcoded structure modding or other minecraft codebase knowledge, be sure to share your thoughts on how our mod can implement more deep-rooted features on the discord or drop into the server to say hi and share your ideas for the mod.
